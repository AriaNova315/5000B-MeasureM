# 输入模板和演示数据

- `input-template.xlsx`：空白字段模板，列顺序与导入器一致。先填写再导入。
- `demo-project.xlsx`：从零构造的虚构项目，包含阶段1、双周、阶段和里程碑节点，可用于验收。

两份文件由 `scripts/create_examples.py` 创建，不含真实项目数据，不需要联网。
项目组成员和任务资源使用英文逗号分隔；日期填 Excel 日期，工作量单位为人时。
里程碑的两个“生成报告”字段需同时填“是”或同时填“否”。
`基线组成`保留输入格式，目前 MeasureM 不使用其内容。
含公式的正式输入文件应先在桌面 Excel 中重算并保存，MeasureM 读取其已保存的公式结果。

根目录的原始业务 Excel、数据库和历史导出不会放入交付包。
